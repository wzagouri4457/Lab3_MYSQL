Lab 3 : Sélection et filtrage de données
ce TP consiste a Construire des requêtes SELECT simples et avancées.
Utiliser WHERE avec les opérateurs de comparaison, logiques, LIKE, IN, BETWEEN et gérer les NULL.
Ordonner les résultats (ORDER BY), paginer (LIMIT/OFFSET) et agréger les données (COUNT, SUM, GROUP BY).
Appliquer ces concepts à des scénarios concrets de gestion de bibliothèque.
